# Movement Engineering Lab Website

Website for the Movement Engineering Lab at Universidad Católica del Uruguay.

**Live site:** https://ucumovinglab.github.io

## Features

- Automatic publication fetching from ORCID (monthly)
- Bilingual content (Spanish/English)
- Team member profiles
- Research project pages
- Research lines, publications and team driven from `_data/` files
- Responsive, accessible design (WCAG AA contrast, keyboard focus, works without JS)

## Local Development

### Prerequisites

- Ruby 3.x
- Python 3.x
- Bundler

### Setup

```bash
# Install Ruby dependencies
bundle install

# Install Python dependencies (for citation generation)
pip install -r _cite/requirements.txt

# Generate citations
python _cite/cite.py

# Run the site locally
bundle exec jekyll serve
```

The site will be available at http://localhost:4000

## Structure

```
├── _config.yaml              # Site configuration
├── _data/
│   ├── i18n.yml              # All UI strings, English and Spanish
│   ├── projects.yaml         # The three research lines (titles, text, figures, selected papers)
│   ├── sources.yaml          # Tags publications with a research line; hides superseded preprints
│   ├── orcid.yaml            # ORCID IDs for the monthly publication sync
│   ├── citations.yaml        # Generated by _cite/cite.py in CI — do not edit
│   ├── collaborators.yaml    # Collaborating groups and people
│   └── alumni.yaml           # Former students
├── _members/                 # One file per person (bio_en / bio_es in front matter)
├── _layouts/                 # home, research, publications, team, member, post, default
├── _includes/                # header, footer, publication entry, figures/ (schematic SVGs)
├── assets/css/main.css       # The whole design system (tokens at the top)
└── index.md, es/index.md …   # Pages: front matter only; content comes from _data
```

English and Spanish pages share layouts. Each page sets `lang` and a `ref` shared with its translation; the language switch links the two.

## Adding Content

### Team member

Create `_members/firstname-lastname.md`:

```yaml
---
name: Full Name
image: images/team/firstname-lastname.jpg   # portrait, 4:5, at least 800×1000
role: phd   # pi, phd, masters, undergrad, postdoc, staff
author_match: Lastname   # used to bold the name in author lists and build the profile's publication list
lines: [motor-control]
interests_en: ...
interests_es: ...
bio_en: >-
  ...
bio_es: >-
  ...
links:
  email: email@ucu.edu.uy
  orcid: 0000-0000-0000-0000
---
```

The Students section of the Team page appears automatically once a student exists.

### Publications

The ORCID sync lists everything the members have published. To make a paper part of the lab's own list (the default view, the homepage and member profiles), add its DOI to `_data/sources.yaml` with a `line:`. Use `hide: true` for preprints that have since been published.

### Figures

`_includes/figures/*.svg` are schematic figures drawn from normative gait data, not lab data. Replace them with real figures as they are published; keep the 360×200 frame for research lines.

## Deployment

The site automatically builds and deploys via GitHub Actions when you push to the `main` branch. Publications are refreshed monthly.
